# Chat Markdown Scroll Milestone

时间：2026-05-12

## 设计目标

优化 `/chat` 会话页面的生成体验：模型输出过程中允许用户上划查看历史内容，避免流式生成时强制拉回底部；助手消息默认按 Markdown 渲染；当输出包含 fenced code block 时，在代码块中提供复制按钮。

## 计划内容

- 为消息区增加自动滚动状态，只在用户位于底部附近时跟随生成。
- 用户上划查看历史时暂停自动滚动，并在生成中显示“回到底部”按钮。
- 生成结束后只刷新左侧历史摘要和顶部会话信息，不重新打开当前会话，避免右侧消息区清空重绘。
- 助手消息使用本地轻量 Markdown 渲染，不引入外部 CDN。
- fenced code block 渲染为独立代码块，并提供复制按钮。

## 实施调整

- Markdown 渲染仅覆盖 AI 输出常见语法：标题、段落、列表、引用、链接、行内代码和 fenced code block。
- 用户消息继续按纯文本展示，避免用户输入被误解析。
- Thinking 内容继续作为 Assistant 消息内的可展开区域展示，暂不按 Markdown 渲染。
- 链接仅允许 `http`、`https`、站内路径和锚点，模型输出中的 HTML 会先被转义。

## 验收标准

- 流式生成长文本时，用户上划后页面不会被强制滚回底部。
- 用户点击“回到底部”后恢复跟随生成。
- 生成完成后当前消息区不闪烁、不重建、不跳动。
- Markdown 内容默认以预览形式展示。
- fenced code block 右上角有复制按钮，并能复制完整代码。
- `/chat` 和 `/admin` 页面可正常打开。
