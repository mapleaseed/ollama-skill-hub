# Milestones

本目录用于记录 Ollama Skill Hub 的里程碑式改动。

约定：

- 每次里程碑式改动先在 Plan 模式下形成设计。
- 设计完成后，在本目录新增一份里程碑文件。
- 开发过程中如果需求变化，需要同步更新对应里程碑文件。
- 本文件维护总体摘要和改动时间。

## 里程碑摘要
