# Chat Config UX Milestone

时间：2026-05-12

## 设计目标

优化 `/chat` 输入区的运行配置交互。参考主流 AI 聊天产品的处理方式，将用户最常切换的模型信息保持可见，把低频配置收纳到高级设置面板中，避免“模型配置”和“确认配置”两个按钮造成重复确认感。

## 计划内容

- 将模型适配器和模型名提升到输入框上方，作为当前会话运行上下文。
- 将 Agent、Skill、RAG、Top K、Thinking、流式输出放入高级设置面板。
- 保留“完成”按钮用于关闭高级设置，不再表达提交或确认配置。
- 配置值仍然在发送任务时从当前控件读取，不改变后端 API。

## 实施调整

- `模型配置` 按钮改为 `高级设置`。
- `确认配置` 从输入区操作栏移入高级设置面板，改名为 `完成`。
- 高级设置面板增加标题和说明，用于明确其影响范围。
- 移动端下模型区和高级设置自动改为单列布局。

## 验收标准

- 输入区默认能直接看到模型适配器和模型名。
- 点击高级设置可以展开或收起 Agent、Skill、RAG、Thinking、流式输出等配置。
- 点击完成只关闭面板，不触发额外提交。
- 发送任务时仍然携带原有配置字段。
