# Chat Codex UI Milestone

时间：2026-05-12

## 设计目标

优化 `/chat` 页面视觉质感，参考 Codex 类工作台界面的低噪声、强阅读、弱装饰风格。重点减少表单感和卡片堆叠感，让历史会话、消息流和底部输入区更像一个持续工作的对话环境。

## 计划内容

- 将整体配色从偏米色调整为中性浅灰和白色，降低装饰性。
- 左侧历史会话改为更紧凑的侧栏列表，减少阴影和卡片厚度。
- 消息区改为文档流样式，Assistant 输出不再像表单卡片。
- 底部输入区保留浮层 composer，但弱化边框和配置区噪声。
- 原生文件输入收敛为单一“添加附件”按钮，保持最多 5 个文件的逻辑不变。

## 实施调整

- 保留现有 `/chat` API、流式输出、Markdown、代码复制、Thinking 和滚动逻辑。
- 仅调整 `web/chat.html` 的结构和样式，不改变后端字段。
- 高级设置仍然使用原有控件，只在视觉上收纳为低频配置区域。
- 按 Codex 的交互进一步收敛：底部仅保留小 `+` 配置入口、单一附件入口、模型名和发送按钮。
- 配置改为弹出式面板，左侧选择配置分类，右侧显示对应配置项。
- 模型主体展示模型名称，适配器仅作为灰色辅助信息和 hover 提示。
- 移除 `/chat` 中的管理页跳转入口，避免会话页承担管理页导航。
- 顶部会话标题支持编辑，保存后写入 SQLite；标题编辑不改变会话最近更新时间。
- `file://` 方式打开 `chat.html` 时，前端自动请求 `http://127.0.0.1:8011` 的 API，便于本地直接预览。
- 附件选择改为前端队列管理，支持多次选择累计到 5 个文件，并在输入框上方按 Codex 风格展示文件卡片、扩展名和移除按钮。
- 附件文件卡片按常用扩展名展示类型化图标标签和配色，覆盖 Office、PDF、文本、Markdown、日志、配置、图片、音视频、代码、数据、压缩包、可执行文件、数据库、设计稿、字体和系统库文件；未知类型显示扩展名而不是空白图标。

## 验收标准

- `/chat` 页面视觉更接近工作台式对话界面。
- 历史列表、消息流、输入区层级清晰，不出现大面积厚重卡片。
- 文件上传控件展示为干净按钮，已选附件以文件卡片可视化展示，并可单独移除。
- 现有发送、配置、上传、Markdown 渲染和流式滚动能力不回退。
